Start the agent

Do this once, on any Windows, macOS or Linux computer that is connected to this network and can stay switched on.

  1. Install Python 3.9 or newer on that computer (Windows: python.org, tick “Add python.exe to PATH”). The agent needs nothing else — no extra packages.
  2. Download the agent into a folder of your choice:
    netwatch_agent.py
  3. Open a terminal in that folder (Windows: Command Prompt, then cd to the folder) and save the connection settings once: python netwatch_agent.py --server {{ server_url }} --key {{ key_text }} --save {% if not new_key %}The key is not shown again after it is created. Use New key above if you do not have it.{% endif %}

  5. Run it continuously and leave the window open: python netwatch_agent.py

To find the devices on the network, run python netwatch_agent.py --scan on the agent computer. It lists every address that answers, so you can register them here.
