Sites & on-site agents

A site is a private network (LAN) — an office, a lab, a hotspot. Devices on it use private addresses such as 192.168.1.1 or 10.150.121.187, which the cloud server cannot reach. A small agent program running on any computer inside that LAN checks them and reports the results here.
